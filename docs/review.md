# 移植审查记录

本记录是同一实现者完成的自查，不是独立第三方审查。GitHub PR/CI 的状态应以实际链接和运行结果为准。

## 对照方法

1. 从原 SLX 提取三个函数、参数和端口，保存源模型 SHA-256 与三个函数文件的哈希。
2. 将原函数中的标量表达式、if/elseif 和固定 for 循环转换为 Python 求值；未根据 C 代码编写参考公式。
3. 编译实际 C 动态库，通过 ctypes 对 17 个输出逐项比较。
4. 增加独立解析静力学检查：水平静止无截煤力时，左右支撑力均为 Mg/2、反作用力矩互为相反数、牵引力及平衡残差为零。
5. 检查牵引力限幅、非负支撑力、油缸力幅值、角度直通、载荷取绝对值、非法输入和参数、数值溢出、错误时输出不变，以及输入/输出缓冲区重叠。

## 审查后修正

- 在油缸几何截断前检查非有限中间结果，避免 NaN 被 C 的 fmin/fmax 截断掩盖。
- 在需求牵引力与支撑力截断前检查数值异常。
- 错误时不输出部分计算结果；使用 17 元素局部缓冲区，全部计算成功后才复制到调用方。
- 头文件与实现的数组参数声明保持一致，便于严格告警编译。
- 明确 MATLAB 参数从 1 编号、C 数组从 0 编号；保留未使用的 P(2)、P(3)，避免其后参数错位。
- 原模型中的 `Larm` 在整机函数里未参与计算，C 整机函数不保留这个无效局部变量；摇臂函数仍使用它。

## 继承原模型、没有更改的行为

- 固定 12 次迭代，不增加按误差停止的迭代，也不保证所有工况收敛。
- 牵引命令转矩仅参与近零速方向判定；本模块不计算电机实际能提供多少牵引力。
- 左右滚筒法向力的方向在公式内固定，输入取绝对值；不能表达任意方向反转的载荷。
- 油缸输出是非负负载幅值，不是带方向外力；联接 AMESim 时需核对外力符号。
- 油缸几何越界时原式使用余弦截断与最小力臂，可能给出有限但不具物理可行性的结果。
- 牵引余量使用已限幅的力，饱和后只到零，不会显示负的需求余量。
- 不求机身位移、速度、俯仰或摇臂角度；三个角度输出是直通。
- 若接入带等效运动质量的液压模型，必须另外确认惯性划分和加速度反馈，不能从本次移植一致性推断联合模型正确。

## 验证范围

数值容差：每个输出满足 `abs(error) <= max(1e-6, 2e-12*abs(reference))`。
不同单位的输出分别在 `reference/ports.json` 中命名；不能把一个总的绝对误差当作统一物理误差。
对接近零的平衡残差，优先看绝对误差，而不是相对误差。

`validation-local.json` 保存最终一次本机运行的编译器、工况数、分支计数、逐输出误差及 C 文件哈希。
宽范围随机测试含超载、支撑脱离和非工作几何，验证的是分支与数值一致性，不能当作有效工况分布。

因此结论是“标量方程 C 移植已验证”，不是“整机模型已完成目标板实时部署”。
